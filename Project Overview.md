# Project Overview

This file mirrors the maintained overview in [`project-overview.md`](/Users/patrickcarroll/Dropbox/Creative%20Projects/Programs/pc_journal/project-overview.md).

It exists because this project folder's local instructions explicitly ask for a Markdown file called `Project Overview`.

The maintained overview also records the current shared visual baseline from
[`PC_Design System.md`](/Users/patrickcarroll/Dropbox/Creative%20Projects/Programs/Design/PC_Design%20System.md): IBM Plex Mono, neutral day/night tokens, the optional cyan-and-orange Nautical appearance, square one-pixel framing, and reduced-motion support.

The main editor uses a solid, full-height reading column with faint vertical
rules. It masks the Nautical grid behind the text while keeping that grid in
the surrounding workspace.

The journal's toolbar reports only the current calendar year's dated-entry
words, and the library includes year, month, and date controls for direct
navigation in long multi-year journals.

`today` takes the full editor to the current entry, while `focus` opens the
dated entry at the current caret or selected in the library. The overlay shows
an entry word count, has its own typewriter mode, edits that entry's body inside
the same HTML document, and continues to use the normal autosave path.

It also documents the native iPhone/iPad companion in
[`ios/JournalMobile`](/Users/patrickcarroll/Dropbox/Creative%20Projects/Programs/pc_journal/ios/JournalMobile), which opens and edits the same HTML journal file from iCloud Drive.
